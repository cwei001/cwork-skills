# BP 概念术语详解

## 一、核心概念

### 1. BP（Business Plan）

BP 是**业务规划**的缩写，是一种目标管理方法论。通过设定目标、拆解关键成果、执行关键举措，实现业务的系统化管理。

### 2. OKR

**O**bjectives and **K**ey **R**esults，目标与关键结果。

| 组成 | 说明 | 示例 |
|------|------|------|
| **O（目标）** | 定性的方向描述 | "提升产品用户体验" |
| **KR（关键结果）** | 定量的可衡量指标 | "NPS 提升至 50" |

### 3. BROW

**B**usiness **R**esult **O**bjectives and **W**orkbacks，业务结果目标与逆推。

一种以**业务结果为导向**的目标管理方式，先确定期望达成的业务结果，再逆推需要完成的关键工作。

### 4. 目标（Objective）

**定义**：定性的方向描述，回答"我要做什么"。

**特征**：
- 鼓舞人心，有挑战性
- 时间周期内可达成
- 团队/个人可控制

**示例**：
- "打造行业领先的 AI 产品"
- "提升客户满意度至行业第一"

### 5. 关键成果（Key Result）

**定义**：定量的衡量指标，回答"如何证明目标达成"。

**特征**：
- 必须可衡量（量化）
- 有明确的完成标准
- 有截止时间

**示例**：
- "AI 产品收入占比达到 40%"
- "客户 NPS 提升至 50 分"

### 6. 关键举措（Action/Key Action）

**定义**：具体的执行任务，回答"具体要做什么事"。

**特征**：
- 可执行的具体行动
- 有明确的责任人
- 有明确的截止时间

**示例**：
- "完成 AI 诊断功能开发"
- "上线用户反馈系统"

---

## 二、层级关系

```
目标（O）
  └── 关键成果（KR）
        └── 关键举措（Action）
```

**层级拆解原则**：
- 1 个目标 → 2~5 个关键成果
- 1 个关键成果 → 3~5 个关键举措
- 关键举措是可直接执行的任务

---

## 三、周期类型

| 周期 | 说明 | 典型时间 |
|------|------|----------|
| **年度 BP** | 全年业务规划 | 1月~12月 |
| **季度 OKR** | 季度目标 | Q1/Q2/Q3/Q4 |
| **月度复盘** | 月度进展回顾 | 每月 |

---

## 四、角色定义

| 角色 | 说明 |
|------|------|
| **undertaker（负责人）** | 对任务负主要责任的人 |
| **collaborator（协作者）** | 参与协助完成任务的人 |
| **observer（观察员）** | 知情但不需要执行的人 |
| **supervisor（督导）** | 监督任务执行的人 |

---

## 五、状态定义

| 状态 | 说明 |
|------|------|
| **草稿（draft）** | 刚创建，还未正式发布 |
| **进行中（in_progress）** | 正在执行 |
| **已完成（completed）** | 已完成 |
| **已关闭（closed）** | 已取消或终止 |

## 六、衡量标准（SMART 原则）

好的关键成果应符合 **SMART** 原则：

| 字母 | 含义 | 说明 |
|------|------|------|
| **S**pecific | 具体 | 描述清晰，无歧义 |
| **M**easurable | 可衡量 | 可以量化，有具体数字 |
| **A**chievable | 可达成 | 努力可以实现 |
| **R**elevant | 相关 | 与目标方向一致 |
| **T**ime-bound | 有时限 | 有明确的截止时间 |

**Good vs Bad 示例**：

| Good ✅ | Bad ❌ |
|---------|--------|
| "AI 产品收入达到 500 万" | "提升 AI 产品收入" |
| "NPS 提升至 50 分" | "提高客户满意度" |
| "Q4 完成上线" | "尽快完成" |

## 七、填报流程

### Step 1：创建目标
1. 登录 BP 系统
2. 选择周期（如 2026 年度）
3. 新建目标，填写目标名称和描述
4. 指定负责人

### Step 2：拆解关键成果
1. 在目标下新增关键成果
2. 填写衡量标准（必须量化）
3. 设置目标值和当前值
4. 指定责任人和截止时间

### Step 3：制定关键举措
1. 在关键成果下新增关键举措
2. 填写具体执行任务
3. 指定负责人和截止时间
4. 定期更新进展

### Step 4：填写汇报
1. 在任务详情页点击"汇报"
2. 填写进展、问题、下一步计划
3. 提交后更新任务状态

## 八、常见概念误区

### ❌ 误区 1：目标 = 关键成果
**正确**：目标回答"做什么"，关键成果回答"做到什么程度"

### ❌ 误区 2：关键成果 = 关键举措
**正确**：关键成果是衡量标准，关键举措是具体执行

### ❌ 误区 3：衡量标准模糊
**正确**：必须有具体数字，如"提升 20%"

### ❌ 误区 4：时间倒挂
**正确**：举措截止 ≤ 成果截止 ≤ 目标截止

### ❌ 误区 5：责任真空
**正确**：每个节点必须有明确的 undertaker
