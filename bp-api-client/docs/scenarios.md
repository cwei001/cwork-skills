# BP 使用场景与判断逻辑

## 一、核心场景分类

使用 BP 助手时有两大类场景：

| 场景 | 说明 | 示例 |
|------|------|------|
| **📚 问知识** | BP 概念、流程、术语问答 | "什么是 OKR？""怎么填 BP？""BROW 是什么？" |
| **🔍 查数据** | 查询 BP 系统中的实际数据 | "帮我查一下产品部的目标""张成鹏的 BP 进展如何" |

---

## 二、场景判断逻辑

### 快速判断规则

| 用户表述关键词 | 意图判断 |
|--------------|---------|
| "什么是""是什么意思""解释" | 问知识 |
| "怎么填""如何创建""如何操作" | 问知识 |
| "帮我查""看一下""查询" | 查数据 |
| "BP 进展""目标进度""完成情况" | 查数据 |
| "OKR""BROW""关键成果" | 可能两者皆有，先确认 |

### 判断流程

```
用户提问
    ↓
关键词匹配
    ├─ 知识类关键词 → 查 docs/concepts.md
    ├─ 数据类关键词 → 调用 API 查询
    └─ 不确定 → 询问用户确认
```

## 三、查询数据场景详解

### 场景 1：查"某某某的 BP"

**用户意图**：查看该人**个人节点**下的目标/成果/举措

**查询方式**：
```
1. 获取组织树找到该人的个人节点 ID
2. 用个人节点 ID 查任务树: /bp/task/v2/getSimpleTree?groupId={个人节点ID}
3. 返回该人个人 BP 目标
```

**示例**：
- "查张成鹏的 BP" → 查个人节点下的目标
- "帮我看看封敏的 BP" → 查个人节点下的目标

---

### 场景 2：查"负责人是某某某" / "责任人是某某某"

**用户意图**：**不确定**，可能是以下两种情况之一：

#### 情况 A：想看该人个人节点下的 BP
- 同场景 1 的查询方式

#### 情况 B：想看该人参与的所有任务（跨部门）
- 查询部门任务树
- 在结果中筛选 taskUsers 中包含该人的任务
- 匹配字段: `taskUsers[].empList[].id == 员工ID`

**判断要点**：
- 如果该人在部门中有个人节点 → 可能是情况 A
- 如果该人是其他任务的协作者/负责人 → 可能是情况 B

**必须询问用户确认**：
> "您是想看张成鹏个人的 BP 目标，还是他参与的所有任务？"

---

### 场景 3：查部门 BP

**用户意图**：查看某部门（如产品部、技术部）的整体目标

**查询方式**：
```
1. 获取周期 ID
2. 获取部门 groupId
3. 查询部门任务树
```

---

### 场景 4：查具体目标详情

**用户意图**：查看某个目标/成果/举措的完整信息

**查询方式**：
```
已知 ID → 直接调用 getGoalAndKeyResult / getKeyResult / getAction
未知 ID → 先查任务树获取 ID
```

---

### 场景 5：查汇报记录

**用户意图**：查看目标/成果/举措的进展汇报

**查询方式**：
```
调用 pageAllReports 接口
参数：taskId（目标/成果/举措 ID）
```

---

## 四、规划助手场景

### 核心场景：基于已有目标规划新任务

**用户典型表述**：
- "我现在有一件 XX 任务要做，帮我根据已有目标看一下..."
- "我要做 XX 事情，应该怎么调整 BP？"
- "我想新增/修改一个目标/成果/举措..."

**助手判断逻辑**：

```
用户有新任务要做
    ↓
查询该用户当前 BP 结构（目标→成果→举措）
    ↓
判断新任务与现有 BP 的关系：
    ├─ 属于现有目标的延伸？ → 建议新增关键成果或举措
    ├─ 与现有目标相关但独立？ → 建议新增关键成果
    ├─ 全新业务方向？ → 建议新增目标
    └─ 替代或调整现有任务？ → 建议修改现有目标/成果/举措
    ↓
提供具体操作建议
```

## 五、关键字段说明

### 员工 ID vs 个人节点 ID

| 类型 | 用途 | 示例 |
|------|------|------|
| 个人节点 ID (groupId) | 查个人 BP 任务树 | 2013466265741791233 |
| 员工 ID (empId) | 在 taskUsers 中匹配参与的任务 | 1514822105176903682 |

### 角色类型

| 角色 | 说明 |
|------|------|
| undertaker | 负责人 |
| collaborator | 协作者 |
| observer | 观察员 |
| supervisor | 督导 |

## 七、常见问题

### Q1：查不到某人的 BP 怎么办？
- 确认该人是否有个人节点
- 确认周期是否正确
- 可能是该人还未创建 BP

### Q2：查到的目标和预期不符怎么办？
- 确认查询的是个人节点还是部门
- 可能是查询了不同的周期

### Q3：汇报记录为空怎么办？
- 该任务可能还未填写汇报
- 汇报可能被删除或归档
